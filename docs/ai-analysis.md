# 外部 AI 分析约束

插件不内置 AI 分析，也不直接生成能力地图。AI 只能读取导出的 ZIP，并把分析结果作为独立产物保存。

## 可重跑要求

每次分析至少记录：

- 使用的 ZIP 文件名或哈希
- 分析时间
- Prompt 版本
- 模型名称
- 输入页面目录，例如 `pages/page-001`
- 输出 JSON 文件名

## 页面分析 Prompt v0.1

```text
分析该页面。

输入材料：
1. page.html：页面原始 HTML
2. screenshot.png：页面截图
3. page.json：页面元数据、菜单路径、页面元素派生结果、人工备注
4. network.json：已脱敏网络请求

要求：
- 不要覆盖原始证据。
- 如果信息不足，字段值写为“无法判断”。
- 如果存在人工菜单路径，以人工补充为优先依据，并保留自动识别路径作为参考。
- 区分事实、推测和待人工确认内容。

输出：
1. 页面名称
2. 页面用途
3. 主要功能
4. 涉及对象
5. 用户角色
6. 核心字段
7. 核心操作
8. 推测所属能力域
9. 可开放能力

JSON格式输出。
```

## 系统事实库还原 Prompt V1

当目标是从采集 ZIP 还原系统模块、页面、页面关系、业务动作、流程节点和待确认问题时，使用：

- [system-fact-restore-prompt-v1.md](system-fact-restore-prompt-v1.md)

该提示词强调事实优先、推理单独标记、缺失信息不补全。输出中所有需求分析辅助结论必须标记为【事实】或【推测】。

## 能力域标准

```text
工单域
资产域
保修域
客户域
服务商域
组织域
知识域
项目域
结费域
任务书域
权限域
```

允许新增，但新增能力域必须说明依据。
